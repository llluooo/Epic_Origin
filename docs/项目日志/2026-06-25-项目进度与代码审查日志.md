## 当前项目进度

### 主流程

- 已具备主菜单、种族选择、主地图探索、据点管理、资源获取、事件触发、兵营遭遇、敌方据点入口、回合推进和胜负判定的基础链路。
- 主地图由 `MapGenerator` 生成，`MapManager` 提供格子查询、坐标转换和可达性判断。
- `Hero` 支持格子移动、当前格交互和移动范围校验。
- `GameManager` 负责玩家/电脑数据、回合流转、资源产出、召唤、战斗入口和结果结算。

### 战斗链路

- 已接入 `Assets/Scripts/Battle` 下的基础战斗系统，包括战斗卡牌包装、伤害计算、AI 出牌、防守选择、投降判断、战斗管理和战斗界面。
- 兵营与敌方据点现在通过 `GameManager` 发起战斗。
- 已加入运行时状态层 `GameSession` 与纯数据状态 `GameRunState`、`MapState`、`PendingBattleState`、`PendingBattleResult`。
- 当前战斗切换目标是单场景切换：进入战斗前捕获主地图状态，加载 `BattleScene`；战斗结束后写入结果，再加载 `MainScene` 并恢复状态。

### 地图与据点

- 地图支持随机生成和从 `MapState` 重建。
- 地图格子类型已覆盖空地、资源、事件、兵营、据点和障碍物。
- 玩家据点仍使用当前 `StrongholdUI`，敌方据点进入战斗，不再直接用战力比较结束游戏。

### UI 与视觉

- 已有主菜单、种族选择、主 HUD、据点管理、单位卡牌、卡牌视图和战斗 UI。
- 据点 UI 保留当前实现。
- 种族选择和地图热点已有基础反馈组件。
