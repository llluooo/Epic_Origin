# 《史诗起点》项目日志：种族选择 UI 更新

生成时间：2026-05-30

## 1. 更新范围

本次更新集中在 `RaceSelectScene` 的种族选择体验，目标是把原本偏功能性的三族选择流程升级为更有叙事感和视觉区分度的 UI：

- 三族地图式选择入口
- 三族详情页展示
- 文本文案框资源
- 英雄图与文案区域布局
- 返回主菜单与返回地图的交互规则

## 2. 已完成内容

### 2.1 三族地图选择页

- 新增三界主图资源：
  - `Assets/UI/RaceSelect/race_select_three_realms.png`
- 新增三族地图热区相关资源：
  - `hotspot_human_mask.png`
  - `hotspot_heaven_mask.png`
  - `hotspot_ghost_mask.png`
  - `hotspot_human_frame.png`
  - `hotspot_heaven_frame.png`
  - `hotspot_ghost_frame.png`
- 地图页交互设计为左/中/右三块区域分别对应人族、天族、鬼族。
- 热区支持不规则点击区域与点击反馈，用于避免纯矩形按钮带来的误触和视觉割裂。

### 2.2 种族详情页

- `RaceSelectUI` 已从原先的按钮选择逻辑扩展为“地图页 + 详情页”面板切换逻辑。
- 每个种族选项现在可配置：
  - 种族类型
  - 地图热区按钮
  - 高亮反馈图
  - 英雄图
  - 文案框图
  - 显示名
  - Inspector 中填写的种族描述文案
- 详情页保留左侧英雄展示、右侧标题与正文的布局方向。
- 文案内容不在代码中写死，后续仍由 Inspector 填写。

### 2.3 文本框资源

- 使用内置生图模型生成三族详情页文本框资源：
  - `Assets/UI/RaceSelect/DetailFrames/detail_human_text_frame.png`
  - `Assets/UI/RaceSelect/DetailFrames/detail_heaven_text_frame.png`
  - `Assets/UI/RaceSelect/DetailFrames/detail_ghost_text_frame.png`
- 三个文本框保持统一的暗金史诗 UI 风格，同时通过种族装饰区分：
  - 人族：城邦、石墙、红金纹章
  - 天族：白金、圣环、云纹、圣光
  - 鬼族：紫黑、幽火、裂纹、幽域装饰
- 曾生成的英雄边框资源仍保留在 `DetailFrames` 目录，但当前 UI 方案暂时不使用英雄边框；如需取消，只需在 `RaceSelectUI` 的 `Hero Frame Image` 与各族 `Hero Frame Sprite` 中保持空引用。

### 2.4 脚本交互更新

- `RaceSelectUI` 增加详情页框图切换能力：
  - `heroFrameImage`
  - `textFrameImage`
  - `heroFrameSprite`
  - `textFrameSprite`
- 进入不同种族详情页时，脚本会自动切换英雄图、标题、正文和文本框图。
- 新增 `Esc` 返回规则：
  - 只有停留在三族地图页时，按 `Esc` 返回 `MainMenuScene`。
  - 进入种族详情页后，按 `Esc` 不做任何事。
  - 详情页只能通过 `返回` 按钮回到三族地图页。
- 保持原有确认进入游戏流程：
  - 设置 `GameSetupData.PlayerRace`
  - 从另外两个种族中随机 `GameSetupData.EnemyRace`
  - 设置 `GameSetupData.IsNewGame = true`
  - 进入 `MainScene`

## 3. Unity 场景接线要点

当前场景接线由 Unity Editor 中手动完成，核心规则如下：

- `DetailPanel` 背景可使用暗化版 `race_select_three_realms.png`，保持地图页与详情页风格连续。
- `TextFrameImage` 应位于 `DetailTitleText` 和 `DetailBodyText` 下方渲染。
- `TextFrameImage` 的 `Raycast Target` 应关闭，避免遮挡按钮或文本交互。
- 三个 `Race Options` 中分别拖入对应种族的 `Text Frame Sprite`。
- 如果暂时不使用英雄边框：
  - `Hero Frame Image` 保持空引用，或禁用场景中的 `HeroFrameImage`
  - 各族 `Hero Frame Sprite` 保持空引用
