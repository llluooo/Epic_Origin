# 《史诗起点》项目日志：据点UI重设计

生成时间：2026-06-20

## 1. 更新范围

本次更新重写了据点交互的 UI 和核心逻辑，从简单的弹出面板升级为全屏据点管理界面：

- 召唤从随机改为可选 + 数量控制
- 据点操作不再消耗回合行动
- 双相机切换实现据点/地图隔离
- 卡组信息融入召唤界面

## 2. 已完成内容

### 2.1 据点面板整体

- `StrongholdUI` 完全重写，从弹窗改为全屏面板（Screen Space Overlay）
- 进入据点 → 关闭主相机 + 禁用 InputManager → 显示据点面板
- 离开据点 → 恢复主相机 + 恢复 InputManager
- 支持 ESC 键离开、按离开按钮离开
- 顶部实时显示据点等级、金币、建材

### 2.2 兵种召唤

- 新增 `UnitCardUI` 组件，每张卡牌独立管理：
  - 卡牌美术图（从 Inspector 配置的种族 Sprite 数组加载）
  - 名称/等级/ATK/HP/消耗/已有数量
  - 数量选择器：`[-] [输入框] [+]`
  - 召唤按钮（显示总价 = 单价 × 数量）
- 三种状态：锁定（等级不足）、资源不足（消耗红色）、可召唤
- 0.5 秒防连点冷却
- 输入非法值自动修正到有效范围
- 召唤成功后即时刷新所有卡牌状态和已有数量

### 2.3 升级据点

- 升级按钮独立于回合行动
- 满级（Lv5）自动隐藏升级按钮
- 升级后立即刷新所有卡牌解锁状态

- 鬼族 5 张：骷髅/僵尸/鬼火/死亡骑士/死神
