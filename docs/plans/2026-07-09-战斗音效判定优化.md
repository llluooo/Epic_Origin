# 战斗音效判定优化 — 设计方案

**日期**: 2026-07-09
**分支**: merge/merge_feature
**目标**: 优化战斗场景中的音效播放判定逻辑，使攻/防/阵亡音效在正确的时机触发，并在战斗结束时暂停BGM。

---

## 当前问题

1. `ExecuteRound()` 中 Attack / Defend 音效无视攻防方，每回合必定同时播放
2. 卡牌全灭阵亡时只打 `Debug.Log`，没有播放音效（SFX 枚举中也缺少阵亡音效）
3. 战斗胜利/失败时只播放 SFX，没有暂停背景 BGM

## 修改方案

### 涉及文件

| 文件 | 改动 |
|------|------|
| `Assets/Scripts/Audio/AudioEnums.cs` | 新增 `UnitDeath` 枚举值 |
| `Assets/Scripts/Scenes/Battle/BattleManager.cs` | 修改 `ExecuteRound()` 和 `CheckBattleEnd()` 的音效/BGM 逻辑 |

### 1. AudioEnums.cs — 新增 SFX.UnitDeath

在 SFX 枚举的战斗分类中添加 `UnitDeath`（单位阵亡）：

```
// ---- 战斗 ----
CardSelect,
CardCancel,
Attack,
Defend,
TakeDamage,
UnitDeath,      // 新增：单位阵亡
```

### 2. BattleManager.ExecuteRound() — 条件化攻/防音效 + 阵亡音效

**Attack**：仅玩家方为攻击方时播放（`isPlayerAttacking == true`）
**Defend**：仅玩家方为防守方时播放（`isPlayerAttacking == false`）
**TakeDamage**：保持不变，双方受击都播放
**UnitDeath**：防守方卡牌阵亡时（`!defender.IsAlive()`）播放

```csharp
// 我方进攻时播放攻击音效
if (isPlayerAttacking && AudioManager.Instance != null)
    AudioManager.Instance.PlaySFX(SFX.Attack);

// ... 伤害计算 ...

// 我方防守时播放防守音效
if (!isPlayerAttacking && AudioManager.Instance != null)
    AudioManager.Instance.PlaySFX(SFX.Defend);

defender.TakeDamage(attackDamage);

// 受击音效（双方都播）
if (AudioManager.Instance != null)
    AudioManager.Instance.PlaySFX(SFX.TakeDamage);

// 无论哪方阵亡，都播放阵亡音效
if (!defender.IsAlive() && AudioManager.Instance != null)
    AudioManager.Instance.PlaySFX(SFX.UnitDeath);
```

### 3. BattleManager.CheckBattleEnd() — 胜负时停止BGM

在玩家胜利/敌方胜利判定中调用 `StopBGM()`：

```csharp
if (playerAlive && !enemyAlive)
{
    outcome = BattleOutcome.PlayerVictory;
    battleResult = "玩家胜利";
    AudioManager.Instance?.StopBGM();
    AudioManager.Instance?.PlaySFX(SFX.BattleVictory);
}
else if (!playerAlive && enemyAlive)
{
    outcome = BattleOutcome.EnemyVictory;
    battleResult = "敌方胜利";
    AudioManager.Instance?.StopBGM();
    AudioManager.Instance?.PlaySFX(SFX.Defeat);
}
```

### 4. BattleManager.Surrender() — 逃跑时也停止BGM

保持一致性，玩家投降时同样停止 BGM：

```csharp
battleEnded = true;
AudioManager.Instance?.StopBGM();
// ...SFX.Flee 已在现有逻辑中...
```

---

## 退回地图的BGM恢复

无需额外处理。`BattleSceneBridge.ResolveAndReturn()` 加载 MainScene，而 `UIManager.Start()` 已包含 `AudioManager.Instance?.PlayBGM(BGM.Map)`，会自动恢复地图背景音乐。

---

## Unity Editor 操作步骤

1. 打开 **Audio Enums.cs** 确认 `UnitDeath` 枚举值已添加
2. 选中 `Assets/` 中的 **AudioLibrary** ScriptableObject 资产
3. 在 Inspector 中找到 SFX 库列表，为新增的 **UnitDeath** 条目拖入对应的阵亡音效 AudioClip
