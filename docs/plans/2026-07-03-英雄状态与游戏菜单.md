# 英雄状态与游戏菜单

Date: 2026-07-03

## Summary

为大地图场景添加两个新 UI 面板：按 Tab 打开英雄状态界面查看卡牌，按 Esc 打开游戏菜单（继续/存档/读档/设置/退出）。

## Changes

### 1. 英雄状态面板 (HeroStatusUI.cs)

**新建** `Assets/Scripts/Scenes/Main/UI/HeroStatusUI.cs`

- `public GameObject panel` — 面板根节点
- `public TMP_Text[] cardNameTexts` — 5 个卡牌名称文本（对应 5 个兵种）
- `public TMP_Text[] cardQuantityTexts` — 5 个卡牌数量文本
- `public Image[] cardImages` — 5 张卡牌图片
- `Toggle()` — 开关面板
- `RefreshCardDisplay()` — 遍历 `GameManager.Instance.player.deck`，按 unitIndex 分组统计数量，更新 UI
- `Open()` — 激活 panel，禁用 InputManager，调用 RefreshCardDisplay()
- `Close()` — 隐藏 panel，启用 InputManager
- `Update()` — 检测 Tab 键关闭面板

与现有 StrongholdUI 的输入阻断模式一致。

### 2. 游戏菜单面板 (GameMenuUI.cs)

**新建** `Assets/Scripts/Scenes/Main/UI/GameMenuUI.cs`

- `public GameObject panel` — 菜单根节点
- `public Button continueButton` — 继续游戏，调用 Close()
- `public Button heroStatusButton` — 英雄状态，调用 Close() 后打开 HeroStatusUI
- `public Button saveButton` — 存档，调用 Close() 后打开 SaveGameUI
- `public Button loadButton` — 读档，显示内嵌的存档槽位列表
- `public Button settingsButton` — 设置（占位），显示"功能开发中"提示
- `public Button exitButton` — 退出游戏，显示确认对话框
- `public GameObject loadSlotContainer` — 存档槽位容器
- `public GameObject confirmExitPanel` — 退出确认面板
- `public TMP_Text placeholderMessage` — 设置占位文本
- `Toggle()` — 开关菜单
- `Open()` — 激活 panel，禁用 InputManager，初始化槽位
- `Close()` — 隐藏 panel，启用 InputManager，关闭子面板
- `ShowLoadSlots()` — 刷新并显示读档槽位列表
- `OnLoadSlotClicked(int slot)` — 调用 `SaveSystem.LoadManualGame(slot)`，存入 `GameSession`，`SceneManager.LoadScene("MainScene")` 重载
- `OnExitConfirmed()` — 确认退出，`SceneManager.LoadScene("MainMenuScene")`
- `Update()` — 检测 Esc 键关闭菜单

### 3. UIManager 修改 (UIManager.cs)

- `public HeroStatusUI heroStatusUI` — Inspector 拖入 HeroStatusUI 引用
- `public GameMenuUI gameMenuUI` — Inspector 拖入 GameMenuUI 引用
- `Update()` 中添加键盘检测（仅当 `!isBattleActive && !gameEnded`）：
  - `Input.GetKeyDown(KeyCode.Tab)` — 若 GameMenuUI 未开，调用 `heroStatusUI.Toggle()`
  - `Input.GetKeyDown(KeyCode.Escape)` — 若 HeroStatusUI 未开，调用 `gameMenuUI.Toggle()`

### 4. 读档流程

读档无需离开场景：`SaveSystem.LoadManualGame(slot)` → JSON 反序列化 → `GameSession.UpdateRunState(loadedState)` → `GameSetupData.IsNewGame = false` → `SceneManager.LoadScene("MainScene")` → `GameManager.RestoreGameFromSession()` 自动恢复。
此流程与主菜单读档（SaveSelectUI → MainScene）一致，只是跳过了中间的 SaveSelectScene。

## Implementation Notes

- GameMenuUI 仅在玩家回合且战斗未激活时可打开（Tab/Esc 检测加 `!isBattleActive && !gameEnded` 守卫）
- 面板之间互斥：HeroStatusUI 打开时不响应 Esc（防冲突，反之亦然）
- SaveGameUI 已有 Esc 关闭逻辑，从 GameMenuUI 打开后由 SaveGameUI 自身处理
- 设置按钮占位：显示 3 秒提示文本后自动隐藏
- 卡牌显示分组：遍历 `player.deck.cards`，按 unitIndex 分组计数（现有存储模型是每张卡独立 Card 对象）
- 遵循现有 UI 模式：禁用 InputManager 阻断地图点击，GameObject.SetActive 控制面板显隐
- 退出确认：点击"退出游戏"显示确认面板（"确定要退出吗？" + 确认/取消按钮），确认后加载 MainMenuScene
