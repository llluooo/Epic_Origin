# 据点种族背景图

Date: 2026-07-01

## Summary

为 StrongholdUI 面板添加种族对应的据点背景图，打开据点时根据玩家种族切换显示。

## Changes

### 1. 背景图字段与切换逻辑 (StrongholdUI.cs)

- `public Image backgroundImage` — 背景图 UI Image 组件引用
- `public Sprite humanStrongholdBg` — 人族据点背景
- `public Sprite heavenStrongholdBg` — 天族据点背景
- `public Sprite ghostStrongholdBg` — 鬼族据点背景
- `GetBackgroundForRace(RaceType race)` — 按种族返回对应背景 Sprite，复用 `GetCardSpritesForRace()` 的 switch 模式
- `Open()` 中调用 `GetBackgroundForRace(p.race)` 设置 `backgroundImage.sprite`
- 现有卡牌美术、摄像机切换、面板显隐、输入管理等逻辑不变

## Implementation Notes

- 背景图字段放在卡牌美术字段 (`humanCardSprites` 等) 附近，保持代码组织一致
- 如果 `backgroundImage` 为 null，跳过设置，不报错（与现有 nullable 检查风格一致）
