# 战斗逃跑功能设计方案

## 概述

在战斗中为玩家添加"逃跑"按钮，点击后有 50% 概率成功脱战，50% 概率失败并受到惩罚（所有己方卡牌 HP 减半）。整合原有的投降功能，统一为逃跑决策。

## 涉及文件

| 文件 | 操作 |
|------|------|
| `Assets/Scripts/Scenes/Battle/BattleManager.cs` | 添加 `AttemptFlee()` 方法 |
| `Assets/Scripts/Scenes/Battle/BattleUI.cs` | 添加逃跑按钮及其逻辑 |
| `Assets/Scripts/Shared/Session/BattleSceneBridge.cs` | 添加 `PlayerFled` 到 `BattleOutcome` 枚举 |
| `Assets/Scripts/Scenes/Main/GameManager.cs` | 处理 `PlayerFled` 结果（无惩罚脱战） |

## 详细设计

### 1. BattleOutcome 新增枚举值

在 `BattleSceneBridge.cs` 的 `BattleOutcome` 枚举中添加 `PlayerFled`（玩家逃跑成功）。

### 2. BattleManager 添加逃跑逻辑

新增 `AttemptFlee()` 方法：

```
public bool AttemptFlee()
  - 50% 概率 (Random.value < 0.5f)
  - 成功:
    - battleEnded = true
    - outcome = BattleOutcome.PlayerFled
    - battleResult = "玩家逃跑成功"
    - 播放 SFX.Flee + StopBGM
    - 返回 true
  - 失败:
    - 所有玩家卡牌 currentHP 减半 (至少保留 1)
    - 同步更新 currentCount
    - 播放 SFX.Flee
    - 切换回合给敌方 (isPlayerAttacking = false)
    - 返回 false
```

### 3. BattleUI 添加逃跑按钮

- 在 `[Header("回合控制")]` 区域添加 `public Button fleeButton` 字段
- 在 `BindControls()` 中绑定 `fleeButton.onClick` 到 `OnFlee()`
- 在 `UpdateControlState()` 中控制逃跑按钮可见性：
  - 仅在 `isPlayerAttacking` 且战斗未结束时显示
  - 非动画播放中
- `OnFlee()` 方法：
  1. 隐藏攻击按钮和逃跑按钮
  2. 调用 `battleManager.AttemptFlee()`
  3. `RefreshUI()` 刷新界面
  - 如果战斗结束，走正常结算流程
  - 如果失败，界面切换到敌方回合

### 4. GameManager 处理 PlayerFled

在 `ResolveBattleResult()` 中添加对 `PlayerFled` 的处理：
- 与 Draw 类似，无奖励无惩罚
- 直接返回地图继续游戏

原有 `PlayerSurrender` 处理逻辑保留不动（旧代码兼容）。

### 5. 音效

- `SFX.Flee` 枚举和音频文件已存在
- 逃跑成功和失败都播放 `SFX.Flee`
- 逃跑成功时额外调用 `StopBGM()`

## Unity 操作步骤

1. 选中 BattleScene 中的 **BattleUI** GameObject
2. 在 BattleUI 组件的 Inspector 中，将场景中的逃跑按钮拖入新增的 **Flee Button** 字段
3. 确保场景中有对应的逃跑按钮 UI 元素（Button），如果没有需创建并设置文字为"逃跑"
