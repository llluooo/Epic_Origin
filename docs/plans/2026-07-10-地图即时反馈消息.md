# 地图即时反馈消息

Date: 2026-07-10

## Summary

将地图格子和回合产出的即时反馈消息接入 `MessageLogUI`，让玩家在 HUD 消息区域看到操作结果，而非仅在 Console 查看。

## Changes

### 1. 空地 (EmptyTile.cs)

- `OnHeroEnter()` 增加 `MessageLogUI.Instance?.AddMessage("空地")`

### 2. 资源点 (ResourceTile.cs)

- `OnHeroEnter()` 增加反馈：`"获得资源: {amount}金币"` 或 `"获得资源: {amount}建材"`

### 3. 事件点 (EventTile.cs)

- 每种事件增加对应 `MessageLogUI` 反馈：
  - 古代宝藏: "触发事件【古代宝藏】: 获得 200 金币！"
  - 流浪商人: "触发事件【流浪商人】: 获得 150 建材！"
  - 英雄遇仙: 每张卡牌单独反馈
  - 强盗袭击: "触发事件【强盗袭击】: 损失 X 金币！"
  - 沙尘暴: "触发事件【沙尘暴】: 本回合无法再进行主操作！"
  - 瘟疫: 按结果区分反馈

### 4. 兵营 (ArmyCampTile.cs)

- `OnHeroEnter()` 增加 `"进入兵营"` 反馈
- 战斗结果已有 MessageLogUI 调用，无需改动

### 5. 据点 (StrongholdTile.cs)

- 己方据点: 增加 `"进入己方据点"`
- 敌方据点: 增加 `"进入敌方据点"`

### 6. 障碍物 (ObstacleTile.cs)

- 不改动（IsWalkable=false，正常流程不会被踩）

### 7. 回合产出 (GameManager.cs)

- 玩家据点产出已在 L370 接入 MessageLogUI，无需改动

## Implementation Notes

- 所有 `Debug.Log` 保留不变，`MessageLogUI.AddMessage()` 为额外追加
- 使用 `MessageLogUI.Instance?.AddMessage(...)` 安全空传播调用
