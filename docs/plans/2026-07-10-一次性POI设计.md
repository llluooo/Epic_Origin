# 一次性 POI 设计（兵营/资源点/事件点消失机制）

## 背景

当前地图上兵营、资源点、事件点可以无限次交互，导致严重 bug。需要改为一次性 POI，交互后即消失。

## 需求

1. **兵营** — 战胜后兵营消失，无法再进入（战败保留）
2. **资源点** — 占领后消失，据点每回合产出增加
3. **事件点** — 到达后即消失
4. **AI 同步** — AI 踩点也触发同样清除效果，双方共享地图、先到先得

## 架构方案

### 核心思路

在 `Tile` 基类增加 `Cleared` 属性和 `MarkCleared()` 方法，各类 POI 交互后标记清除并隐藏 POI 视觉。`TileState.cleared` 字段已存在，接入存档流程。

### 涉及文件

| 文件 | 改动 |
|------|------|
| `Tile.cs` | 新增 `Cleared` 属性、`MarkCleared()` 方法 |
| `TileVisual.cs` | 新增 `HidePoi()` 公开方法 |
| `MapManager.cs` | 新增 `ClearTileAt(Vector2Int)` 方法 |
| `ResourceTile.cs` | `OnHeroEnter` 中检查 `Cleared`，处理后标记清除 + 增加据点产量 |
| `EventTile.cs` | `OnHeroEnter` 中检查 `Cleared`，处理后标记清除 |
| `ArmyCampTile.cs` | `OnHeroEnter` 中检查 `Cleared` |
| `GameManager.cs` | `ResolveBattleResult` 传入 `sourceTilePos`，战胜后清除兵营格子 |
| `AIHero.cs` | `OnAIEnterTile` 中检查 `Cleared`，处理后标记清除 |
| `Player.cs` | 新增 `capturedResourceCount`，产出公式叠加资源点加成 |
| `GameRunState.cs` / `TileState` | `FromTile` 捕获 `Cleared` 状态 |
| `MapGenerator.cs` | `PlaceRestoredTile` 恢复 `Cleared` 状态 |

## 详细设计

### 1. Tile 基类 — 清除标记

```csharp
// Tile.cs 新增
public bool Cleared { get; private set; }

public virtual void MarkCleared()
{
    if (Cleared) return;
    Cleared = true;
    TileVisual vis = GetComponent<TileVisual>();
    if (vis != null) vis.HidePoi();
}
```

### 2. TileVisual — 隐藏 POI

```csharp
// TileVisual.cs 新增
public void HidePoi()
{
    if (poiRenderer != null) poiRenderer.enabled = false;
}
```

### 3. MapManager — 清除格子

```csharp
// MapManager.cs 新增
public void ClearTileAt(Vector2Int pos)
{
    Tile tile = GetTileAt(pos);
    if (tile != null && !tile.Cleared)
    {
        tile.MarkCleared();
        Debug.Log($"格子 {pos} 已清除（{tile.GetType().Name} → 空地）");
    }
}
```

### 4. ResourceTile — 占领后消失 + 增加产出

```csharp
public override void OnHeroEnter()
{
    if (Cleared) return; // 已清除，跳过
    
    // ... 原有逻辑（获得金币或建材）...
    
    // 增加据点产量
    GameManager.Instance.player.capturedResourceCount++;
    MarkCleared();
}
```

### 5. EventTile — 触发后消失

```csharp
public override void OnHeroEnter()
{
    if (Cleared) return;
    
    // ... 原有逻辑 ...
    
    MarkCleared();
}
```

### 6. ArmyCampTile — 检查清除状态

```csharp
public override void OnHeroEnter()
{
    if (Cleared) return;
    
    // ... 原有逻辑（启动战斗）...
}
```

清除时机在战斗胜利结算时（见 GameManager 改动），而非进入时。

### 7. GameManager — 战斗结算后清除兵营

当前流程：`ResolveBattleResult(encounterType, outcome)` 不传 `sourceTilePos`。

**改动**：增加 `sourceTilePos` 参数，传递到 `ResolveArmyCampBattle`。战胜后调用 `MapManager.Instance.ClearTileAt(sourceTilePos)`。

```csharp
// RestoreGameFromSession 中
ResolveBattleResult(result.encounterType, result.outcome, result.sourceTilePos);

// ResolveArmyCampBattle 中，战胜逻辑末尾
MapManager.Instance.ClearTileAt(sourceTilePos);
```

### 8. AIHero — AI 交互后清除

```csharp
private void OnAIEnterTile(Tile tile)
{
    if (tile.Cleared) return;
    
    // ... 原有逻辑 ...
    
    // AI 处理完后标记清除
    if (tile is ResourceTile || tile is ArmyCampTile || tile is EventTile)
    {
        // AI 占领资源点也增加 AI 的产出
        if (tile is ResourceTile)
            GameManager.Instance.aiPlayer.capturedResourceCount++;
        tile.MarkCleared();
    }
}
```

### 9. Player — 资源点产出加成

```csharp
// Player.cs 新增字段
public int capturedResourceCount;

// 修改 GetTurnProduction()
public ResourceData GetTurnProduction()
{
    ResourceData base = BaseProduction[strongholdLevel];
    int bonus = capturedResourceCount * 20; // 每个资源点 +20
    return new ResourceData(base.gold + bonus, base.buildingMaterials + bonus);
}
```

### 10. 存档/读档 — TileState.cleared 接入

**TileState.FromTile** 捕获 `cleared` 状态：

```csharp
// 在 FromTile 中增加
state.cleared = tile.Cleared;
```

**MapGenerator.PlaceRestoredTile** 恢复 `cleared` 状态：

```csharp
// 在 PlaceRestoredTile 末尾
if (state.cleared)
{
    Tile tile = map[state.position.x, state.position.y];
    if (tile != null) tile.MarkCleared();
}
```

## 交互流程

### 玩家踩资源点
```
Hero.OnHeroEnter → ResourceTile.OnHeroEnter
  → 检查 Cleared（false）
  → 发放资源奖励
  → player.capturedResourceCount++
  → MarkCleared() → TileVisual.HidePoi()
```

### 玩家踩兵营（战胜）
```
Hero.OnHeroEnter → ArmyCampTile.OnHeroEnter
  → 检查 Cleared（false）
  → 进入战斗场景 → 战斗 → 返回主场景
  → RestoreGameFromSession → ResolveBattleResult(..., sourceTilePos)
  → ResolveArmyCampBattle → 战胜奖励 → MapManager.ClearTileAt(pos)
```

### AI 踩资源点
```
AIHero.OnAIEnterTile → 检查 Cleared → 发放奖励
  → aiPlayer.capturedResourceCount++
  → MarkCleared()
```

## 边界情况

- **同一回合多次踩点**：`hasPlayerActed` 机制已防止
- **战败后重试兵营**：战败不触发清除，可再次挑战
- **清除后存档**：`TileState.cleared` 序列化保证恢复正确
- **清除的格子可通行**：POI 格子本身 `IsWalkable=true`，清除后不变
- **据点格子不受影响**：仅 ResourceTile/EventTile/ArmyCampTile 参与清除
